# UPDATE 209 - Inchidere fiscala controlata

Versiune: 2.12.189

- Marcarea lunii ca depusa cere recipise acceptate D300, D394, D112 si D406.
- Ecranul de inchidere arata declaratiile lipsa si pasul de rezolvare.
- Statusul depusa nu poate fi aplicat manual peste declaratii incomplete.
- Rezultatul verificarii fiscale este inclus in raspuns si audit.
