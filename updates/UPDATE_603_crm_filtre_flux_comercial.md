# UPDATE 603 — CRM: filtre rapide pentru fluxul comercial

Versiune: `2.12.583`  
Data: `2026-09-28`

## Ce aduce

- Cardurile din **CRM / Vânzări → Flux comercial** deschid lista de oferte filtrată pe etapa aleasă.
- Sunt disponibile etapele: oferte de aprobat, așteaptă client, acceptate și oferte cu comandă client confirmată.
- În lista ofertelor, un panou discret arată filtrul rapid activ și permite revenirea la toate ofertele cu un singur click.

## Verificare

1. Deschide **CRM / Vânzări**.
2. Apasă fiecare card din **Flux comercial**.
3. Verifică titlul filtrului rapid din **Oferte**.
4. Apasă **Șterge filtrul rapid** pentru a reveni la lista completă.
