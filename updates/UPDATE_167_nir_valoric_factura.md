# UPDATE 167 - NIR valoric si factura furnizor

Versiune: 2.12.147

- Receptiile solicita pret unitar si cota TVA pe linie.
- NIR-ul pastreaza baza, TVA si totalul documentului.
- Costul mediu ponderat al materialului se recalculeaza la intrare.
- Dintr-un NIR necorelat se poate crea o factura furnizor draft.
