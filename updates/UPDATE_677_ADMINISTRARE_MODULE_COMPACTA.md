# UPDATE 677 — Administrare module compactă (v2.12.657)

## Ce se schimbă

- Setări → Module începe cu un rezumat al modulelor active, modulelor de bază, categoriilor și ultimei salvări.
- Onboarding-ul, fluxurile documentelor și pachetele comerciale se deschid separat, numai la cererea administratorului.
- Catalogul modulelor este grupat în categorii pliabile; categoria operațională este deschisă inițial pentru acces rapid.

## Siguranță

- Nu sunt eliminate module, funcții, setări, permisiuni, date sau audituri.
- Activarea, configurarea funcțiilor și salvarea modulelor folosesc aceleași acțiuni existente.
- Nu există migrări de bază de date și nu se modifică fluxurile operaționale.
