# UPDATE 633 — v2.12.613 — Notificări citite per utilizator

## Comportament nou

Clicul pe o notificare din bara de sus o marchează citită pentru utilizatorul
curent și deschide în același timp destinația relevantă.

## Protecția alertelor operaționale

- confirmarea de citire este individuală, nu globală;
- ceilalți utilizatori își păstrează propriile notificări;
- pentru alertele calculate din starea operațională, confirmarea este legată de
  conținutul curent al alertei. Dacă situația se schimbă, alerta poate reapărea.
