# UPDATE 149 - Contabilitate plan de conturi actiuni

Versiune: 2.12.129
Data: 2026-06-25

## Schimbari

- Planul de conturi foloseste dropdown `Actiuni cont` pentru contul selectat.
- Actiunile disponibile sunt grupate: fisa cont, editare, familie, analitic si activare/dezactivare.
- `DropdownMenu` accepta corect separatoare definite prin `type: 'separator'`, folosite de meniurile contabile noi.
- Importurile nefolosite din Plan de conturi au fost curatate.

## Verificare

- `npm run build` in `client`.
