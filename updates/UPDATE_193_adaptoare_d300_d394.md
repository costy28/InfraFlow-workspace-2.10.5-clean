# UPDATE 193 - Adaptoare D300 si D394

- Candidatii XML folosesc radacina, namespace-ul si campurile obligatorii din profilul XSD al perioadei.
- D300 grupeaza bazele si TVA-ul pe cote; D394 pastreaza operatiile pe tert si document.
- Campurile obligatorii nemapate sunt raportate explicit.
- Fisierul este considerat utilizabil numai dupa acceptarea validatorului configurat.
