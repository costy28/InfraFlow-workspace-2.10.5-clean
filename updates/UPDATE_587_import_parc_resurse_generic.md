# UPDATE 587 — Import parc & resurse generic

Versiune: `v2.12.567`  
Data: `2026-09-27`

## Ce aduce

- Un tab nou în **Parc & Resurse**: **Import parc & resurse**.
- Modele descărcabile Excel și XML, neutre față de furnizorul de origine.
- Import de autovehicule și/sau utilaje, cu actualizare după numărul de înmatriculare, respectiv codul utilajului.
- Audit pentru fiecare import de fișier.
- Terminologie comercială neutră pentru adaptoarele opționale de alimentări și parc extern.

## Cum se folosește

1. Deschide **Parc & Resurse → Import parc & resurse**.
2. Descarcă modelul Excel sau XML.
3. Completează una sau ambele categorii, fără a redenumi anteturile/câmpurile.
4. Încarcă fișierul și verifică rezultatul importului.

Nu sunt șterse resurse; un identificator deja existent actualizează înregistrarea respectivă.
