# UPDATE 146 - Contabilitate actiuni compacte in facturi

Versiune: 2.12.126
Data: 2026-06-25

## Schimbari

- Actiunile din Facturi intrare si Facturi iesire sunt grupate intr-un dropdown per rand.
- Meniul afiseaza contextual actiunile disponibile pentru factura: editare, validare, plata/incasare, devalidare, storno, nota contabila si fisa tertului.
- Tabelele de facturi raman mai aerisite pe desktop si se comporta mai bine pe ecrane inguste.
