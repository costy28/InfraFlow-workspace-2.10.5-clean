# UPDATE 658 — Canale update Stable și Preview

Versiune: `2.12.638`  
Data: `2026-10-03`

- Stable este canalul implicit pentru orice instalație client.
- Superadmin poate selecta Preview numai pentru Demo sau pentru licențe care au `update.preview` ori `update.preview_permis` activ.
- Catalogul semnat este filtrat după canal atât la verificare, cât și la instalarea online.
- Nu este publicat automat niciun release Preview prin acest update.
