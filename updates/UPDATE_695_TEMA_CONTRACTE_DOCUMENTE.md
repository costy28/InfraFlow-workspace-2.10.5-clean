# UPDATE 695 — Tema vizuală în Contracte și Documente

Versiune: 2.12.675
Data: 2026-10-06

- Adaptare incrementală a controalelor native și formularelor din Contracte/Documente la tema comună.
- Tabelele native Contracte folosesc spațierea și stările comune; Documente păstrează coloane lizibile prin scroll local.
- Antet Documente unificat și indicatori Contracte cu accent verde.
- Cardurile informative păstrează semnificația succes/atenție/eroare cu suprafețe dark lizibile; anteturile modalelor din aceste pagini respectă tema.
- Nu modifică logica, API-ul, datele, permisiunile, calculele sau documentele printabile. Nu adaugă dependențe.

Validare: build, smoke browser cu API interceptat pentru liste, filtrare Contracte, dosar contract, formulare fără salvare, light/dark și mobil; audit expuneri fișiere și verificări arhive Windows/Linux.
