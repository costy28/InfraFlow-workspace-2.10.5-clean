# Client InfraFlow 1.0

Clientul final va fi o aplicatie Windows standalone cu WebView2.

Responsabilitati:

- citeste adresa serverului din configuratie;
- verifica `/api/v1/version`;
- deschide interfata in fereastra proprie;
- afiseaza mesaj clar cand serverul nu raspunde;
- nu stocheaza baza de date locala.

In aceasta etapa folderul este pastrat ca loc pentru noul client, fara sa
modificam executabilele existente din pilot.
