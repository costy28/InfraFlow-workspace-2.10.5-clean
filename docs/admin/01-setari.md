# Configurare sistem

Setările definesc datele companiei, stația, aspectul documentelor și comportamentul aplicației. Doar administratorii trebuie să modifice aceste informații.

## Pași
1. Deschide **Setări**.
2. Completează numele companiei, CUI, adresa și datele de contact.
3. Completează numele stației.
4. Apasă **Salvează**.
5. Verifică dacă datele apar corect pe documente și rapoarte.

## Note importante
⚠️ Schimbările de setări afectează toți utilizatorii.
