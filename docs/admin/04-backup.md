# Backup și restore

Backup-ul protejează datele aplicației. Este recomandat înainte de update, importuri mari sau modificări importante.

## Pași
1. Deschide **Setări** sau **Sistem**.
2. Apasă **Descarcă backup** sau **Creează backup**.
3. Păstrează fișierul într-un loc sigur.
4. Pentru restore, alege fișierul de backup.
5. Verifică aplicația după restaurare.

## Note importante
⚠️ Restaurarea înlocuiește datele curente. Fă backup înainte de restore.
