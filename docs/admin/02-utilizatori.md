# Gestionare utilizatori

Administratorul poate crea utilizatori, seta roluri și activa sau dezactiva conturi. Rolurile controlează ce module poate vedea fiecare persoană.

## Pași
1. Deschide **Setări** și tab-ul **Utilizatori**.
2. Apasă **Utilizator nou**.
3. Completează numele, utilizatorul, parola temporară și rolul.
4. Salvează contul.
5. Comunică parola temporară persoanei și cere schimbarea ei.

## Note importante
⚠️ Nu acorda rol de superadmin decât persoanelor responsabile de sistem.
