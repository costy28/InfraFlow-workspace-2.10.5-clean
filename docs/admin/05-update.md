# Actualizare sistem

Update-ul aduce funcții noi și corecții. Aplicația verifică serverul de update și instalează pachetul dacă licența permite acest lucru.

## Pași
1. Deschide **Setări** și tab-ul **Update**.
2. Apasă **Verifică actualizări**.
3. Citește noutățile afișate.
4. Dacă există update, apasă **Actualizează**.
5. Așteaptă finalizarea și repornirea aplicației.

## Note importante
⚠️ Se face backup automat înainte de update. Nu opri serverul în timpul instalării.
