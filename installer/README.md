# Installer InfraFlow 1.0

Installerul va avea doua moduri:

- instalare server;
- instalare statie de lucru.

## Server

Instalarea server trebuie sa ceara:

- port;
- conexiune SQL Server;
- firma;
- punct de lucru;
- licenta/trial;
- primul Superadmin;
- module active initial.

## Statie de lucru

Instalarea statiei trebuie sa ceara:

- adresa serverului;
- nume statie;
- departament;
- utilizator propus;
- rol propus.

Parola nu se seteaza pe statie. Adminul aproba cererea pe server si seteaza
parola temporara.
